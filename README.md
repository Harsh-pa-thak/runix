# runix

`runix` is a blazing-fast CLI tool that allows you to cast ASCII spells directly in your terminal. Whether you want to generate high-quality ASCII word art or render classic ASCII illustrations, `runix` has you covered.

## Installation

```bash
cargo install runix-cli
```

## Usage

Generate standard word art (words wider than your screen are stacked to fit):
```bash
runix "Hello"
```

Render illustrations using the `--art` (or `-a`) flag:
```bash
runix wolf -a
runix ghost --art
runix spaceship -a
```
Render illustrations in custom color using the `--color` (or `-c`) flag:
```bash
runix wolf -a -c red
runix ghost --art --color yellow
```
Render random illustrations using the `--random` (or `-r`) flag:
```bash
runix -r
```
Every illustration is automatically fitted to your terminal width — wide art is compressed and long words are stacked, so nothing ever wraps ugly.

Every AI render ends with a tiny readout so you can watch the cache do its job:
```
⚡ 0.42s · ai            ← first time: generated by the AI
⚡ 38µs · local cache    ← every time after: instant
⚡ 0µs · library         ← built-in spells: nanoseconds
```

## How It Works: Built-in + AI + Caching
Once downloaded the user need to set the local <a href="https://console.groq.com/keys">groq</a> api key.

```
runix --set-key <your api key>
```
`runix` uses an intelligent multi-layer pipeline to give you instant art every time:

1. **Built-in Library**: Comes pre-compiled with **100+ classic ASCII illustrations** for instant nanosecond lookups.
2. **Groq AI Generation**: If a word isn't in the library, `runix` casts an AI spell using Groq (`openai/gpt-oss-20b` with low reasoning effort — tuned so typical responses land in well under a second) with a live loading screen showing the elapsed time while you wait.
3. **Generate Once, Use Many (Local Cache)**: Any AI-generated art is automatically saved to your local disk (`~/.runix/cache.json`). Subsequent calls load instantly from your local cache with zero network wait!
4. **Screen Fitting**: AI prompts are capped to your terminal's actual width and height, and every result is fitted to the screen before printing.
5. **Key Security**: The key is securely stored locally  (`~/.runix/config.json`) in this file.
